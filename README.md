# ATaVEE: Post-hoc explanation of span-based predictions in fine-tuned foundation models via influential training examples
Explainable NLP (X-NLP) seeks to provide transparent and trustworthy explanations for how fine-tuned foundation language models make downstream predictions. Within this area, influential-example explanations offer a principled way to explain a prediction by linking it to the training instances that most shape the model’s adapted task behavior. However, many existing influential-example methods rely on parameter-update approximations, reducing alignment with actual model behavior by operating on hypothetical states. Moreover, although influential training examples arise from task-specific fine-tuning rather than pretraining, prior work largely fails to separate pretraining-dominated signals from fine-tuning-induced effects, and does not quantify whether retrieved examples are beneficial or detrimental to predictive accuracy. We propose ATaVEE (Activation-Task-Vector Example-based Explanation), the first post-hoc framework for span-based influential-example explanations in fine-tuned foundation language models. ATaVEE introduces a novel representation space that isolates fine-tuning-induced activation changes and retrieves influential examples through matching in this space. It then quantifies each example’s supportive-versus-misleading effect via counterfactual activation, measuring decision-margin changes under the model’s actual parameters without retraining. Experiments show that ATaVEE retrieves examples that induce substantially stronger influences than random same-label examples, while aggregated polarity aligns with prediction correctness. Ablations and analyses further show that ATaVEE’s key design choices drive these gains.
