# ATaVEE: A method for explaining span-based NLP predictions via influential training examples
Explainable NLP (X-NLP) aims to provide explanations that offer transparent and trustworthy insights into neural NLP models’ decision-making. Within this field, influential-example explanations provide a principled way to explain predictions by linking them to the training instances that most influence them. However, many existing approaches to influential-example explanations rely on parameter-update approximations, reducing alignment with actual model behavior by operating on hypothetical states. Moreover, although influential training examples arise from task-specific fine-tuning rather than pretraining, prior work largely fails to filter out pretraining-dominated signals to isolate fine-tuning-induced effects, and does not quantify whether retrieved examples are beneficial or detrimental to predictive accuracy. We propose ATaVEE (Activation-Task-Vector Example-based Explanation), the first post-hoc framework for span-based influential-example explanations in neural NLP models. ATaVEE introduces a novel representation space that isolates fine-tuning-induced activation changes and retrieves influential examples via matching in this space. It then quantifies each example’s supportive-vs-misleading effect via counterfactual activation, measuring decision-margin changes under the model’s actual parameters, without retraining. Experiments show that ATaVEE retrieves examples that induce substantially larger counterfactual margin shifts than random same-label examples, while aggregated polarity aligns with prediction correctness. Ablations and analyses further show that ATaVEE’s key design choices drive these gains.
